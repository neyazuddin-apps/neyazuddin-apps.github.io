Android automatically shows a prompt whenever an app is installed outside Google Play Store. All APKs listed here are hosted transparently on official GitHub Releases—you can inspect every release page via the GitHub icon on each card.

Note Diary is 100% offline with zero cloud storage—use its built-in Create Backup setting to export an encrypted ZIP file to Google Drive or your PC before uninstalling or changing phones. Driver Diary and Fee Diary support optional Firebase cloud backup where configured.

Privacy Guard runs 100% offline with no internet permission. V Lite Player plays all local videos and music offline. Domino Score works offline too, and only uses internet if you choose to Host or Join a Live Match Sync room.
